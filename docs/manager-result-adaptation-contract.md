# Manager Result → Adaptation Closure Contract

Gate 3 is complete only when this behavior is proven end to end:

1. A human Task reaches a terminal completion state.
2. Desk captures the result with evidence provenance and confidence. A public URL is sufficient for V1; an artist report is an explicit lower-confidence fallback.
3. The relevant Manager review becomes due without the artist prompting Desk.
4. Manager compares the Task/plan hypothesis and success indicators with the observed result.
5. Manager makes an explicit operating decision: repeat, change, stop, or collect more evidence.
6. If the result invalidates remaining work, stale work is superseded through a replacement plan rather than patched in place.
7. The next executable human Task is released automatically from the current canonical plan.
8. Completed accepted work is never recreated unless changed reality invalidates it.
9. Failure during review/replanning preserves the current canonical plan and requeues safely.
10. The artist never needs to ask "what next?" to continue the Mission.

## Non-goals

- A result URL by itself is not completion.
- Creating a review row by itself is not completion.
- Generating analysis text without changing/confirming the operating route is not completion.
- Platform-specific TikTok/Instagram/YouTube integrations are not required for V1.

## Golden proof

For Odaeshi: complete the first resilience-story content Task, attach the published result, allow Desk to review the observed response, and prove that Desk automatically chooses and releases the next exact work without a new artist planning prompt.
